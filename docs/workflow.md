# 工作流

复刻一张论文插图，一共五步。每一步都有明确的产出物和判断标准，别跳步——
尤其是第 2 步（量化），它决定了后面所有数字对不对。

```
①提取  →  ②量化  →  ③写描述  →  ④两后端出图  →  ⑤逐像素验收
```

---

## ① 提取原图

```bash
python tools/extract_figure.py paper.pdf --page 4 --list
python tools/extract_figure.py paper.pdf --page 4 --out qa/reference.png
```

* 先 `--list` 看这页有几组嵌图、显示位置在哪，确认哪一组是目标图。
* 期刊常把大图切条嵌入，工具会按显示位置拼回去（见 pitfalls #12）。
* 如果原图是**矢量**画的（`--list` 里没有对应嵌图），改用
  `--render --dpi 900` 渲染整页，再把图区域裁出来。
* 产出物：`qa/reference.png`，之后所有量测和比对都以它为基准。**不要缩放它**。

## ② 量化版式

按下面的顺序问自己，每一步都有对应的命令：

| 要问的 | 命令 | 拿到的 |
|---|---|---|
| 有哪些填充色？ | `--colors` | 主色列表，直接抄进 `f.color()` |
| 竖线/横线在哪？ | `--row Y` / `--col X` | 墨迹段 `(起点, 终点, 长度)` |
| 这个框的四条边在哪？ | `--box x0,y0,x1,y1` | 描边**外沿**坐标（对虚线也稳） |
| 线宽多少？ | `--row Y` 里段的长度 | 12 / 8 px 之类 |
| 圆角半径多少？ | 在框顶边附近再扫一行 | 直线段起点 − 框外沿 = 半径 |
| 虚线节奏？ | `--dash-y Y --range A,B` | `on / off` 像素数 |
| 文字多大、基线在哪？ | `--text x0,y0,x1,y1` | 每行的包围盒 `y0,y1,h,x0,x1` |

文字基线的推法：

* 该行**没有下降部**（无 g/j/p/q/y）：基线 = 包围盒底边。
* 有下降部：基线 ≈ 底边 − 0.217 em。
* 字号（em）≈ cap 高 / 0.662（全大写或含大写），或 ≈ (上伸到下降) / 0.879。

把这些数字记下来。**不要用眼睛估**——估出来的值在逐像素比对里一定露馅。

## ③ 写图形描述

照 `examples/` 里的脚本改。要点：

* 一个 `Figure(width_px, height_px, width_mm)`；`width_mm` 取成品物理宽度
  （期刊单栏 ~90，双栏 170–190）。
* 坐标直接抄第 ② 步量到的数字，不要"顺便"取整。
* 先用 `z` 值排好层次：容器 `z=1`、面板 `z=2`、小框 `z=3`、嵌图 `z=4`、
  箭头 `z=5~6`、文字 `z=8`。嵌图后面画的框要盖住它。
* 多个同类元素用列表 + 循环（见示例里的 DEI/CEI 指标框），改起来只改一处。

**内容分配原则**：能让读者一眼看懂的图，靠的是"框里一行字 + 结构位置"，
不是框里的段落。如果一个框需要写三行说明，那说明这张图承载了本该写在正文里的内容。

## ④ 两后端出图

```bash
python examples/<case>/build.py
```

产出：

| 文件 | 用途 |
|---|---|
| `*_matplotlib.pdf` | 投稿用（矢量；嵌图按原分辨率） |
| `*_matplotlib.png` | 预览、放进 Word/PPT |
| `*_tikz.tex` | 需要在 LaTeX 里继续编辑时用 |
| `*_tikz.pdf` | 与 tex 同源，已用 xelatex 编译 |
| `*_tikz.png` | 预览 |

**投期刊用哪一版？** 两边都是矢量，任选；要跟正文版式（字体、线宽）完全一致就选
TikZ，因为它的字体和正文由同一套 fontspec 控制。

## ⑤ 逐像素验收

```bash
python tools/verify.py qa/reference.png out/fig1_matplotlib.pdf --mm-per-px 0.029254
```

判读：

| 平均差 | 判读 | 接下来做什么 |
|---|---|---|
| < 12 | 通过 | 交付 |
| 12–45 | 有系统性偏差 | 看"最差分块"的坐标落在哪个元素上，回到 ② 重新量那一块 |
| > 45 | 结构性错误 | 检查是否有元素缺失、整体错位、嵌图没放进去 |

常见症状对照：

* **最差分块集中在图像四周** → 尺度不对（渲染 zoom 错了，见 pitfalls #5）。
* **最差分块沿所有框线分布** → 描边偏移（外沿/中心线混淆，见 pitfalls #2）。
* **某一类元素的框全都不对** → 圆角框二次内缩（见 pitfalls #1）。
* **文字看得清但到处差一点** → 字号差 1–2%，或字体不对。
* **嵌图区域整片糊** → 嵌图被降采样（见 pitfalls #3）。

验收通过后再交付。**不要凭肉眼说"看着一样"就交付**——肉眼看不出 1 px 的偏移，
但印出来 1 px 的偏移在整幅图上就是肉眼可见的"脏"。
